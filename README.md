# 3S QUEST: Tidy Up the Workplace – PT Mattel Indonesia

A virtual reality training simulation prototype focused on the 3S principles (Seiri, Seiton, Seiso) as part of the 5S workplace organization method. This project is developed for PT Mattel Indonesia as an engaging and gamified learning tool.

## Project Description

This VR simulation game serves as a prototype to train employees on the 3S methodology by placing them in an interactive, scenario-based virtual environment. Users can explore multiple maps representing different levels of training difficulty, with tasks designed to simulate sorting, organizing, and cleaning processes in a workplace context.

> This project was created as part of the **Game Developer Concentration Bootcamp** at **President University**.

## Technologies Used

- Unity
- VR (Virtual Reality)

## How to Run the Project

1. Clone or download the repository.
2. Open Unity Hub.
3. Add the project by selecting the folder.
4. Open the project in Unity.
5. Connect a compatible VR headset to test the simulation (if available).
